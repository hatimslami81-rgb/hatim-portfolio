# Hatim — Developer Portfolio

Static personal portfolio for **Hatim** — Python (Django) & Full-Stack Web Developer | Information Engineer.

## Stack

- HTML5 / CSS3 / Vanilla JavaScript
- No build step, no frameworks
- Ready for **GitHub Pages**

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Hero, pitch, stats, featured work |
| `work.html` | Project gallery + filter tabs |
| `experience.html` | Career timeline |
| `skills.html` | Skills matrix + education |
| `contact.html` | Form, contact info, socials, CV |
| `css/styles.css` | Design system & layout |
| `js/main.js` | Nav, motion, filters, form |

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Before you publish

1. Drop your CV at `assets/Hatim_Resume.pdf`.
2. Optional: add GitHub profile URL on `contact.html`.
3. Optional: add experience dates on `experience.html`.

## Deploy to GitHub Pages

1. Push this folder to a GitHub repository.
2. Settings → Pages → Source: Deploy from branch `main` / root (or `/docs`).
3. Site will be live at `https://<user>.github.io/<repo>/`.
